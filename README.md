# XBoost (nama sementara)
Game booster berbasis Shizuku.
- Menu utama: daftar game (tambah game sendiri), tap game = XBoost in-game aktif.
- In-game: bubble melayang (FPS + suhu), tap = panel lengkap (CPU/GPU, suhu, baterai, RAM, memori, app floating).
- Mode Fokus: app user lain di-force-stop + pm suspend, animasi dimatikan; semua dipulihkan saat game ditutup / Stop.
- Performa maksimal (opsional, default aktif): Game Mode performance, fixed performance mode, thermal status override,
  battery saver off, refresh rate dikunci maksimum. Hp bisa lebih panas.
